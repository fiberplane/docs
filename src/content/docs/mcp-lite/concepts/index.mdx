The Model Context Protocol defines several core concepts for building AI-powered applications. The sections below map directly to the MCP specification.

## Core Concepts

- **[Tools](/mcp-lite/concepts/tools/)** - Expose callable functionality to MCP clients
- **[Resources](/mcp-lite/concepts/resources/)** - Provide URI-identified content
- **[Prompts](/mcp-lite/concepts/prompts/)** - Generate message sequences for LLM conversations
- **[Elicitation](/mcp-lite/concepts/elicitation/)** - Request input from clients mid-execution
- **[Sampling](/mcp-lite/concepts/sampling/)** - Request LLM completions from the client

Each concept has specific patterns and best practices that help you build robust MCP servers.
